# Addendum to e90 — 2026-09-25 (Post-PRF cutover, G0.3 revalidation)

## What happened

This addendum documents the revalidation of e90 performed as part of
`G0.3 — Post-PRF Governance Cutover` (commit `3a42d95d`, 2026-09-25).
The goal was to decide between **archiving e90** and **opening e91 as
explicit work**, without re-running the full scorecard (which takes hours).

## Revalidation method (qualitative + history + tool inventory)

The scorecard was last run on 2026-09-21T07:22:23Z, with G5 RED:

```
analytics: p95=367072ms > budget 5000ms
```

Rather than re-running the scorecard, the revalidation compared the
state of the responsible code between the e90 snapshot date and HEAD
(`3a42d95d`):

```bash
$ git log --since="2026-09-21" --oneline \
    -- crates/cognicode-core/src/application/services/graph_insights.rs \
       crates/cognicode-core/src/application/services/community_detector.rs
(empty)
```

**No commits** in either file since the e90 investigation.

Then the revalidation cross-checked the tool inventory of `cognicode-mcp`
v0.98.1 (built from HEAD, 2026-09-25) against the tool names reported
in e90:

- `graph_insights` — **NOT in v0.98.1 tools/list** (20 tools total).
- `graph_communities` — **NOT in v0.98.1 tools/list**.

The v0.98.1 tools/list includes equivalent capabilities under different
names: `build_graph`, `build_call_subgraph`, `get_per_file_graph`,
`trace_path`, `get_complexity`, `find_usages`, `get_hot_paths`,
`query_symbol_index`. There is no `graph_insights` aggregate tool.

**This is decisive**: e90 measured a **v1.0.0-rc** binary, not v0.98.1.
The symptom (p95=367072ms on `graph_insights`) belongs to a different
release line that does not yet exist as `v0.98.1`.

## Decision

- **e90 is closed** as "investigation complete, symptom latent, carried
  forward to e91". The scorecard RED persists until a real fix ships.
- **e91-graph-insights-performance is opened** as the work item that
  will close G5. e91 starts with the WU list proposed at the end of the
  e90 proposal; WU1..WU5 are unchanged except for sequencing.
- The scorecard streak (Gate 2 of v1.0.0 pre-cut checklist) remains
  blocked at 0/3 until G5 is GREEN.

## Implication for v0.98.x

- v0.98.1 is **production-ready contractual** (C7 firmado). The G5
  RED on the v1.0.0 scorecard does NOT apply to v0.98.1: the affected
  tools (`graph_insights`, `graph_communities`) are **not part of the
  v0.98.1 surface**. The two release lines are independent by design.
- e91 is feature work on the **v1.0.0 line**, not maintenance. It does
  NOT trigger a v0.98.x patch release. It belongs to the next minor/major
  release of the v1.0.0 line, not to `docs/roadmap/MAINTENANCE.md`.
