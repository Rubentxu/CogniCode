Propuesta y Alcance

Bug Original

La vista call_graph en el Explorer UI mostraba el SVG en blanco a pesar de que los metadatos (fan in/out, signature) sí renderizaban. La investigación reveló que:

  • call_graph es un ViewKind (intención semántica), NO un block id
  • PaneInspector siempre renderiza <Blocks>, nunca rutas a graph views
  • ViewBlock.tsx no tiene case "call_graph":
  • Schema ContextualView no validaba view_kind (backend lo enviaba, frontend lo ignoraba)

Visión Arquitectónica

Llevar el CogniCode Explorer a una experiencia de exploración estilo Moldable Development (filosofía de GToolkit/GtPager), donde los developers pueden:

  • Navegar visualmente por el knowledge graph
  • Click en nodo abre nuevo pane (Pane Stack) — preserva exploración
  • Guardar y restaurar exploraciones completas (Exploration Snapshot)
  • Cache instantáneo (localStorage) + persistencia duradera (servidor)

Alcance

✅ Dentro del alcance

  • GraphViewRenderer para call_graph
  • Empty state para graphs
  • Pane Stack navigation con dedup
  • Pane State Snapshot (scroll + zoom + pan)
  • localStorage cache + server save
  • Tests Vitest + Playwright

⏭️ Fuera del alcance (futuro)

  • Backend layout endpoint real (sigue mock)
  • dependency_graph, seam_map (soportados pero no wireados)
  • Sharing multi-usuario
  • Conflict resolution para concurrent edits

Decisiones de Diseño

graph TD A[PaneInspector] -->|early-return| B{isGraphViewKind} B -->|true| C[GraphViewRenderer] B -->|false| D[Blocks] C -->|useMemo| E[layoutFromContextualView] C -->|empty state| F[GraphEmptyState] C -->|node click| G[dispatch SELECT_OBJECT] G -->|Pane Stack| H[PanesPaneStackView] H -->|viewport change| I[UPDATE_PANE_VIEWPORT] I -->|localStorage| J[Snapshot Cache] I -->|manual save| K[POST /api/explorations/session]

GraphViewRenderer Routing

Early-return en PaneInspector cuando view_kind ∈ {call_graph, dependency_graph, data_flow, impact_radius, seam_map}

Memoización

useMemo([view.object_id, view.blocks]) evita recálculo en validating

Pane Stack (Opción A)

Click en nodo → SELECT_OBJECT → abre nuevo pane preservando exploración

NO Backward Compatibility

ExplorationSession.panes REQUERIDO sin #[serde(default)] — sesiones legacy inválidas
