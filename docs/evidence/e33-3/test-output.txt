## Refactoring Summary

Original approach: run_cogh() spawned cogh subprocess with unsafe HOME/COGNICODE_HOME env vars.
New approach: Direct function calls to cmd_init(), cmd_install(), cmd_ide_install() with proper
CognicodeHome construction and explicit HOME management.

Key changes:
- lifecycle.rs imports: super::ide::cmd_ide_install; super::layout::{cmd_init, cmd_install, CognicodeHome}
- Test 1: setup_temp_home + run_cogh -> CognicodeHome + cmd_init + cmd_install
- Test 2: setup_temp_home + run_cogh --ide opencode -> CognicodeHome + cmd_init + cmd_ide_install  
- Test 3: setup_temp_home + run_cogh --ide codex -> CognicodeHome + cmd_init + cmd_ide_install
