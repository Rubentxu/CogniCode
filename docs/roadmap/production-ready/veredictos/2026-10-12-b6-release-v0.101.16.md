## Motivo de la excepción

B6 cierra el roadmap 2026-Q4 (B1..B6) con release v0.101.16. CogniCode
puede instalarse, actualizarse, ejecutarse y verificarse de forma
reproducible desde agentes reales sobre repositorios de distintos
tamaños. Las consultas son acotadas, cancelables y observables, sin
depender de Explorer ni de servicios externos obligatorios.

La release v0.101.16 incluye:

- **B6.W1** — Robustez MCP. `ServerLimits` + `ServerDiagnostics` en
  proceso (`crates/cognicode-core/src/interface/mcp/robustness.rs`).
  Init + cierre limpio rc=0 sin huérfanos. JSON-RPC solo por stdout
  (stderr capturado separado). Paginación cursors reales. Timeouts
  fail-fast (<5s vs techo 60s). Sesiones paralelas aisladas. Errores
  estructurados. NO daemon (R-B6-W1: añadir un daemon duplica
  superficie de fallo, el stdio MCP cubre).

- **B6.W2** — Rendimiento reproducible. 6 benchmarks `criterion`
  (cold / hot / incremental / search / navigation / graphs) sobre
  corpus 50 / 500 / 5000 archivos generados en tempdir. 10 budget
  tests con TDD red→green. Mecanismos e91 (PerFileGraphCache,
  OnDemandGraphBuilder, LightweightIndex, CacheStore,
  CallGraphProjection) reusados — no framework nuevo.

- **B6.W3** — Lifecycle `cogh`. `lifecycle.rs` con
  `InstallPlan/InstallAction/InstallOutcome/InstallError`. CLI:
  `cogh install --version X [--rollback Y] [--apply]`. Sin `--apply`
  imprime plan JSON y sale 0. Path resolution orden:
  `$COGNICODE_BIN_DIR` → `$CARGO_HOME/bin` → `$XDG_DATA_HOME/cognicode/bin`
  → `~/.local/share/cognicode/bin` → `/usr/local/share/cognicode`.
  Catalog `cogh` entry: 77 → 81 tools, `install_instructions` +
  `version_check_command` + `ide_compatibility: [cursor, vscode, neovim]`.

- **B6.W4** — Skills y autodescubrimiento. `skills.rs` con
  `load_skills` + `validate_skill_against_catalog` (fail-closed: typos,
  features inexistentes, herramientas experimentales). `product/skills.json`
  con 4 skills (discover / navigate / quality / refactor). 4 evals
  JSON (`evals/discover.json`, `evals/navigate.json`, `evals/quality.json`,
  `evals/refactor.json`). CLI `cogh skills [--json]`.

- **B6.W5** — Certificación de distribución. `cp2-cp4-cp5.json` con 11
  cert entries (4 PASS / 6 NOT_RUN / 1 SKIP_NOT_APPLICABLE). Honest:
  macOS / Windows / MUSL fuera de scope (no se declaran certificados).
  Signing-key custody: SKIP_NOT_APPLICABLE per ADR.

- **B6.W6** — Cierre arquitectónico. ADR-012 PROPOSED: NO split CLI/MCP.
  Tabla de acoplamiento mide 6 tipos compartidos (`AnalysisBasis`,
  `ToolDescriptor`, `Severity`, `CompositeImpactQuery`, B4 enums,
  `assurance_export::envelope::*`). Soft cap 4000 / hard 6000 líneas en
  `commands.rs` y `rmcp_adapter.rs`. C8-R preparado con evidencia
  reproducible (`PENDING_HUMAN_SIGNATURE`).

- **C8-R** — Preparado en `veredictos/2026-10-12-b6-release-v0.101.16-C8-R.md`.
  Estado `PENDING_HUMAN_SIGNATURE` por el operador Ruben. B1..B6
  release SHAs, G1..G6 gate status, UAT/AAT PASS para los 11 items
